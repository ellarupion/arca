# arca

[English](README.md) · **Русский**

*arca* по-латински «ларец»: набор маленьких утилит для Windows.

Один exe, около 50 КБ, без установки и зависимостей, около 15 МБ памяти. Каждую утилиту можно включить или выключить,
arca сама обновляется из GitHub Releases и говорит по-русски и по-английски.

| Утилита | Что делает |
| --- | --- |
| **Светлая/тёмная тема** | Клик по значку ◐ переключает тему Windows. Можно по расписанию. |
| **Корзина** | Корзина у часов: открыть, очистить, автоочистка, если стала слишком большой. |
| **Работа с окнами** | Закрепить окно поверх всех, спрятать в трей, сделать прозрачным, двигать с зажатым Alt. |

## Скачать

Скачайте `arca.exe` в [Releases](https://github.com/ellarupion/arca/releases/latest) и запустите. Нужен .NET Framework 4, он уже есть в Windows 10/11.

## Как пользоваться

Клик по значку arca (ящик) у часов открывает главное меню:

- **Инструменты**: включить или выключить каждую утилиту
- **Настройки…**: открывает `arca.ini`
- **Язык**: как в Windows, English или русский
- **Запускать вместе с Windows**
- **Проверять обновления автоматически** / **Проверить обновления**

### Светлая/тёмная тема

- **Левый клик** по значку ◐: светлая ↔ тёмная
- **Правый клик**: переключение по расписанию (по умолчанию светлая с 07:00, тёмная с 19:00), изменить расписание

Ручное переключение действует до следующего переключения по расписанию.

### Корзина

- **Двойной клик** по значку корзины: открыть корзину (или одинарный, если выключить *Открывать двойным щелчком*)
- **Правый клик**: первым пунктом **Очистить корзину**, дальше открыть, спрашивать перед очисткой, автоочистка больше N ГБ

Когда в корзине что-то есть, на значке появляется точка. Если навести на значок, видно, сколько там файлов и сколько места они занимают.

### Работа с окнами

| Сочетание | Что делает с активным окном |
| --- | --- |
| `Ctrl+Win+T` | Поверх всех окон / отпустить |
| `Ctrl+Win+H` | Спрятать в трей. Клик по его значку возвращает окно |
| `Ctrl+Win+PageDown` | Прозрачнее (до 20%) |
| `Ctrl+Win+PageUp` | Менее прозрачно |
| `Alt` + перетаскивание | Двигать окно, взявшись за любое место (по умолчанию выключено) |

В подменю *Работа с окнами* видны скрытые и закреплённые окна, оттуда их тоже можно вернуть.
При выходе из arca все окна возвращаются как было. Если arca закрыли принудительно, скрытые окна появятся при следующем запуске.

Окна программ, запущенных от администратора, можно менять, только если arca тоже запущена от администратора.

## Настройки

`arca.ini` создаётся рядом с exe и подхватывается сразу после сохранения:

```ini
[arca]
language=auto
updates=1
theme=1
bin=1
windows=1

[theme]
light=07:00
dark=19:00
auto=1

[bin]
doubleclick=1
confirm=1
auto=0
limit_gb=10

[windows]
on_top=Ctrl+Win+T
hide=Ctrl+Win+H
fade=Ctrl+Win+PageDown
unfade=Ctrl+Win+PageUp
alt_drag=0
```

`language`: `auto` (как в Windows), `en` или `ru`.
В сочетаниях можно использовать `Ctrl`, `Alt`, `Shift`, `Win` и любую клавишу (`T`, `F9`, `PageUp`, `Space`…). Пустое значение выключает сочетание.

## Сборка из исходников

Компилятор C# уже есть в Windows, ставить ничего не нужно:

```
build.cmd
```

Получится `arca.exe`. Положите его куда угодно и запустите.

## Обновления

arca проверяет `https://api.github.com/repos/ellarupion/arca/releases/latest` при запуске и раз в 12 часов.
Когда выходит новая версия, появляется уведомление и пункт **Обновить** в начале меню.
Обновление скачивает новый `arca.exe`, подменяет старый и перезапускает arca. Кроме этого запроса никуда ничего не отправляется.
